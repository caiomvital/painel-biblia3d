## B3D-M3 · 13:30 · Programação em blocos, parte 3

**Tópicos (7)**
1. Programar é dar passos na ordem certa para o computador
2. Blocos de repetição: fazer a mesma coisa várias vezes sem copiar
3. Blocos de condição: "se isso acontecer, faça aquilo"
4. Blocos de evento: algo acontece quando clicamos ou apertamos uma tecla
5. Como combinar repetição e condição no mesmo programa
6. Se der erro, procurar o passo que está fora de ordem (depurar)
7. Revisão: rodar o programa e mostrar para um colega

**Perguntas do Desafio da semana**
1. Para que serve um bloco de repetição?
   - Para fazer algo várias vezes sem copiar os blocos *(certa)*
   - Para apagar o programa
   - Para desligar o computador
   - Para mudar a cor do mouse
2. Qual bloco usamos para dizer "se isso acontecer, faça aquilo"?
   - Condição *(certa)*
   - Repetição
   - Som
   - Fim
3. Um programa dá errado. O que fazemos primeiro?
   - Procuramos o passo que está fora de ordem *(certa)*
   - Desistimos
   - Apagamos tudo
   - Trocamos de computador
4. Em programação, o que é um evento?
   - Algo que faz o programa começar uma ação, como um clique *(certa)*
   - Uma festa
   - Um tipo de fio
   - Uma imagem
5. Por que a ordem dos blocos é importante?
   - O computador segue os passos na ordem em que estão *(certa)*
   - O computador escolhe sozinho
   - A ordem não muda nada
   - Só importa a cor dos blocos
